# orbit-runtime

The ORBIT durable workflow runtime: an event-sourced engine with a pure decider, SQLite and PostgreSQL storage, worker registry and dispatch, retries, timeouts, compensation, crash recovery, the HTTP API and the HTTP/JSON and gRPC worker protocols, per-worker identities, TLS and mutual TLS, and OpenTelemetry export.

Part of [ORBIT](https://github.com/AjmalX0/Orbit), a polyglot orchestration language. Licensed under Apache-2.0.
