# orbit-lang

The `orbit` command: compiler driver (`check`, `compile`, `fmt`, `graph`), runtime server (`server`), client (`run`, `deploy`, `status`, `logs`, ...) and language server (`lsp`).

```bash
cargo install orbit-lang
```

Part of [ORBIT](https://github.com/AjmalX0/Orbit), a polyglot orchestration language. Licensed under Apache-2.0.
