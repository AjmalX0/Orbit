# About the project

ORBIT is an open-source workflow language and durable runtime created and
maintained by [AjmalX0](https://github.com/AjmalX0). It is developed in the
open at [github.com/AjmalX0/Orbit](https://github.com/AjmalX0/Orbit) and
released under the Apache License 2.0.
